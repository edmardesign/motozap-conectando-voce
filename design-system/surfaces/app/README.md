# UI kit — app surface

Functional product surface for Bora Zé Delivery, Bora Zé Moto and Bora Zé Mercado. Use for ordering, maps, checkout, tracking, rider/store/admin flows and settings.

Principles: functionality first; compact rhythm; Poppins + Inter for most UI; Anton is not a default app typeface; neon is decorative and rare; touch targets, readability and task completion outrank campaign expression. Marketing patterns do not replace product patterns.
