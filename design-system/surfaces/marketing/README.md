# UI kit — marketing/landing surface

Use para landing Bora Zé, captação de restaurante, mototaxista, cidade nova e campanhas. Não é o app transacional.

Layout: 24px mobile / 96px desktop; max-width 1200px; seção 64px mobile / 96px desktop; grid 12 colunas, gutter 24px. Animação de entrada só na hero, uma vez.

## Componentes
1. HeroSection — Poppins ExtraBold 64/40, Inter 20, CTA Green+Ink, ghost Ink, neon apenas underline/brush.
2. HeadlineBlock — Anton 96px+, uma frase/palavra por linha, fundo White ou Ink.
3. FeatureCard — Lucide 32/1.75, Poppins 20, Inter 16, Fog, r16, p32.
4. StatBlock — Anton 128 Ink, underline Neon 4px, label Inter 14 Mute.
5. CtaBand — full Green, heading Ink 32 (AA), botão White+Ink.
6. Testimonial — White, borda Fog, foto 56, Poppins nome, Inter cidade/frase.
7. FaqAccordion — Poppins 18, Fog divider, chevron 20, Inter 16, 200ms.
8. FooterMarketing — Ink, logo White, links white 70%, social 20, copyright 50%.
9. Badge — NOVO Neon+Ink; PROMO Green+Ink (AA); EM BREVE Fog+Ink.
10. NavbarMarketing — sticky White, logo 32, Inter 15, CTA Green+Ink; mobile drawer full-height.

Ver `specimens.html`, `tokens.d.ts` e `cards.prompt.md`.
