# Bora Zé Design System

Foundations: [Visual](./foundations/visual-foundations.md) · [Brand context](./foundations/brand-context.md) · [Content](./foundations/content-fundamentals.md).

Surfaces: **app** para tarefas transacionais, mapas, pedidos, checkout e operação; **marketing/landing** para vender, explicar, captar e fazer campanha.

Se a pessoa está fazendo uma tarefa dentro do Bora Zé, use app. Se a página está vendendo, explicando, captando ou fazendo campanha, use marketing/landing.

Marketing components: HeroSection, HeadlineBlock, FeatureCard, StatBlock, CtaBand, Testimonial, FaqAccordion, FooterMarketing, Badge, NavbarMarketing.
