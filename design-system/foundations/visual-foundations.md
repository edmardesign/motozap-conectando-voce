# VISUAL FOUNDATIONS + ICONOGRAPHY

## Color tokens
`--bz-white: #FFFFFF` · `--bz-green: #00C24A` · `--bz-neon: #39FF14` · `--bz-ink: #0B0B0B` · `--bz-fog: #F4F6F5` · `--bz-mute: #6B7280`

## 60–30–10
60% white · 30% ink + neutral gray · 10% green accents.

## Contrast
Never neon text on white; never white text on neon. Normal-size text on Bora Green uses Ink because white on #00C24A does not meet WCAG AA. Neon is decorative: strokes, arrows, underlines and giant non-body numerals. Documented exception: NOVO badge = neon background + ink text.

## Typography
Poppins Bold/ExtraBold — titles and impact. Inter Regular/Medium — body and captions. Anton — uppercase campaign/display only. “Anton grita, Poppins fala, Inter explica.” Body line-height 1.5; headings 1.1; ideal line length 60–75ch.

## Spacing
4, 8, 12, 16, 24, 32, 48, 64, 96, 128.

## Radius
8px input/chip · 16px card/button · 24px hero/modal · 999px badge/tag.

## Iconography
Lucide outline, stroke 1.75px, subtly rounded. 20px inline · 24px button · 32px feature · 48px empty state. Inherit text color; action icon uses Bora Green. Never neon icon on white.
